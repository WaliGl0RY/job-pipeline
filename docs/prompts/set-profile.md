# Prompt template: set up your profile

## 1. What this prompt does

It builds your own `profile/master_cv.tex` from the material you already have (an old CV, a LinkedIn export, a pasted list), using the demo CV in `templates/master_cv.example.tex` as the layout. It is the only file `profile/` holds: the single, complete CV that every other step reads. Nothing is invented: whatever your material doesn't say is left out or asked about.

Job data is **not** entered by hand. Postings only arrive through the scraping runs of the search task, and the profile snapshot in `data/cv_profile/` is generated by the first search run from this file, so this prompt doesn't create either.

## 2. What you need to fill in

- $\color{orange}{\texttt{\{\{YOUR\_NAME\}\}}}$: your full name, as it should appear at the top of the CV. Example: `Alex Example`
- $\color{orange}{\texttt{\{\{YOUR\_CONTACT\_DETAILS\}\}}}$: city, phone, e-mail and any personal site to show in the header. Example: `Example City, +00 000 0000000, alex.example@example.com`
- $\color{orange}{\texttt{\{\{YOUR\_CV\_MATERIAL\}\}}}$: everything you have about yourself: an old CV, a profile export or a pasted list of education, projects, jobs, certificates, skills, languages and interests. Example: `the attached old_cv.pdf` or a pasted text
- $\color{orange}{\texttt{\{\{CERTIFICATE\_SOURCES\}\}}}$: where the real certificate documents are, so details can be taken from them. Example: `the three attached certificate PDFs` or `none`
- $\color{orange}{\texttt{\{\{OUTPUT\_LANGUAGE\}\}}}$: the language the master CV is written in, your choice. Example: `English`

## 3. The prompt

```text
Set up my profile for the job pipeline in this repository. The only file to create is profile/master_cv.tex. Write it in {{OUTPUT_LANGUAGE}}.

INPUTS
- My name: {{YOUR_NAME}}
- My contact details: {{YOUR_CONTACT_DETAILS}}
- My material: {{YOUR_CV_MATERIAL}}
- Certificate documents: {{CERTIFICATE_SOURCES}}
- The layout to start from: templates/master_cv.example.tex. Keep its preamble and its \cvheading and cvblock helpers unchanged, and replace the demo person (Alex Example) and every fictional school, employer and project with my real content.

STEPS
1. Create the folder profile/ if it doesn't exist. It is in .gitignore, so nothing in it reaches git. Do not create any other file in it.
2. Copy the template to profile/master_cv.tex and fill in the sections the template has: the header, the introduction paragraph, Education, Projects, Experience, Certifications, Skills, and Languages & Interests. Leave out a section only if my material has nothing for it.
3. Keep it complete and uncut: every project, job, certificate and skill I have. The tailoring step does the cutting for each job later, and it can only choose from what is in this file. Do not shorten it to fit a page limit.
4. Check the file: it must compile as LaTeX if you have an engine, and no demo value may be left. If you can't compile, say so.

TRUTHFULNESS
- Everything must come from my material. Never invent skills, experience, grades, dates or certificate content, and never claim a focus or qualification I haven't stated.
- If something needed is missing or unclear (a date, a grade, the name of a certificate), do not guess: list it at the end as a question.

WHAT THIS PROMPT DOES NOT DO
- Job data is not entered by hand. Job postings come only from the scraping runs of the search task; do not create, import or type in any jobs, and do not create data/ files.
- Do not create the profile snapshot in data/cv_profile/: the first search run generates it from profile/master_cv.tex.

REPORT
Tell me which sections you filled, what you left out because my material had nothing for it, and the open questions.
```

## 4. Why it's written this way

- **One file, because that is all `profile/` holds.** Every routine reads the profile from `profile/master_cv.tex`; nothing reads any other file there.
- **Start from the template, don't generate a layout.** The preamble and helper commands are the layout the tailoring step reuses, so they stay as they are.
- **Complete, not short.** Cutting happens per job at tailoring time. A master CV that is already cut permanently loses items the tailoring step might have wanted.
- **Missing facts become questions.** A guessed date or grade ends up in every tailored CV and cover letter built from this file.
- **Job data is never typed in.** Postings enter the database through the scraping runs, which dedupe and score them. Hand-entered rows would skip both.
- **The snapshot isn't created here.** It carries a hash of the master CV and is regenerated by the first search run whenever the file changes, so a hand-made copy would only go stale.
